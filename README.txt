HOTWIRE / AFTER HOURS EDITION
================

PLAY
Double-click index.html. That is it.
No server, Node.js, install, build step, account, wallet or internet connection is required.
Use a current version of Chrome, Edge, Firefox or Safari with JavaScript enabled.
Keep this folder on disk; extract the ZIP before opening the file.

The entire website, 3D library, game code, styles and logo are embedded in index.html.
The extra transparent logo is included for your branding.

STUDIO
Front / Profile / Rear / 360 camera presets.
Choose paint, lighting and render quality in the Custom Shop.
Photo saves a 1600 x 1000 PNG poster of the current car.
Use Expand game for a full-window cinema layout.

CONTROLS
Lock: Space or tap PICK LOCK when the needle is inside the pink sector.
Ignition: watch the sequence, then use keys 1-4 or tap the colored buttons.
Getaway: A/D, left/right arrows, or the on-screen buttons.
Hold Shift or the NITRO button to boost. Nitro recharges while released. Close passes earn style points and build combos.
P pauses. The sound button toggles audio.
The 3D/ARCADE button switches rendering modes. If WebGL is unavailable, the game uses the perspective arcade renderer automatically.

GITHUB PAGES
1. Upload index.html and .nojekyll to the root of your GitHub repository.
2. Open Settings > Pages.
3. Select Deploy from a branch > main > /(root) and Save.
4. Wait for GitHub to publish your page.
No Actions workflow or npm commands are needed.
Do not upload the ZIP itself: upload the extracted files.

PUMP.FUN
The token is COMING SOON. There is no contract address, launch link, transaction or wallet connection.
The game is free and independent from any token launch.

SCORES
Records are saved only in this browser when storage is available. Some browsers restrict storage on file://; the game remains playable in memory.
The daily challenge resets at midnight UTC.
